# ProjectKelompok4PI
HoaxScanner adalah aplikasi berbasis AI yang dirancang untuk memverifikasi keaslian informasi dan mendeteksi disinformasi/hoaks berbahasa Indonesia. Sistem ini mendukung pemrosesan multimodal, memungkinkan pengguna memeriksa klaim hanya dengan memasukkan teks, tautan berita, gambar, atau video
